UI = 화면 구성 및 User 동작 포함 (버튼을 누르는 동작 등등,,,)

서버 = 다수를 기다리는 쪽 = ServerSocket + while True + 쓰레드 = 그룹채팅

서버 = 여러 클라이언트의 접속을 기다리는 쪽
ServerSocket = 클라이언트 접속을 받는 소켓
while True = 접속 요청을 계속 반복해서 기다림
스레드(Thread) = 접속한 클라이언트마다 동시에 처리

=> 서버는 ServerSocket으로 여러 사용자의 접속을 계속 기다리고, 접속한 사용자마다 스레드를 생성하여 동시에 처리함. 
   이후 메시지를 모든 사용자에게 전달하면 그룹 채팅 구현 가능함.
